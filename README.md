# 교통법규 위반 탐지 (블랙박스 영상)

블랙박스 영상 하나를 넣으면 아래 두 가지 위반 차량을 찾아 **클립(mp4)** 으로 잘라 줍니다.

1. **신호위반** – 빨간불에 정지선을 넘거나 교차로로 출발한 차량
2. **깜빡이 없이 차선 변경** – 방향지시등을 켜지 않았거나 반대쪽을 켜고 차선을 바꾼 차량

클립에 바운딩박스·판정 표시를 넣을지 말지 선택할 수 있습니다.

---

## 1. 처음 설치 (한 번만)

### 준비물
- **Python 3.10 이상** (3.10 ~ 3.13 확인)
  - macOS: 터미널에서 `python3 --version` 으로 확인. 없으면 https://www.python.org/downloads/ 에서 설치
  - Windows: https://www.python.org/downloads/ 에서 설치. 설치 첫 화면에서 **"Add python.exe to PATH" 체크**
- 인터넷 (처음 설치할 때만. 약 2~3GB 패키지를 받습니다)

### 설치 + 실행
압축을 푼 폴더에서

| OS | 방법 |
|---|---|
| macOS | `실행_mac.command` 더블클릭. "확인되지 않은 개발자" 경고가 나오면 파일을 **우클릭 → 열기** |
| Windows | `실행_windows.bat` 더블클릭. "PC 보호" 경고가 나오면 **추가 정보 → 실행** |

처음 한 번은 패키지 설치 때문에 **5~10분** 걸립니다. 그다음부터는 바로 켜집니다.
설치가 끝나면 브라우저가 자동으로 열립니다. 안 열리면 주소창에 `http://127.0.0.1:7860` 입력.

<details>
<summary>터미널로 직접 설치하고 싶을 때</summary>

```bash
# macOS / Linux
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python gui_app.py
```
```bat
:: Windows
py -3 -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python gui_app.py
```
</details>

## 2. 사용법

1. **입력 영상**: 영상 파일을 끌어다 놓거나, 아래 **예시 영상** 중 하나를 누릅니다.
2. **출력 클립에 바운딩박스·판정 표시**: 켜면 차량 박스·신호등·판정 글자가 그려진 클립, 끄면 원본 그대로의 클립.
3. **분석 시작** 클릭 → 결과가 나옵니다.
   - **신호위반 차량**: 위반 순간 앞뒤를 자른 클립
   - **깜빡이 없이 차선 변경한 차량**: 차선 변경 앞 4초 ~ 뒤 2초 클립
   - **판정 내역** 표, **클립 다운로드**
4. 같은 영상으로 바운딩박스 옵션만 바꿔 다시 누르면, 분석은 재사용하고 클립만 새로 만들어 빠릅니다.

결과 파일은 폴더 안 `gui_outputs/<영상이름>_<번호>/` 에 저장됩니다.
- `clips/` (표시 있음) · `clips_plain/` (원본)
- `red_light.csv` 신호위반 목록, `events.csv` 차선 변경 목록(깜빡이 판정 포함)

### 예시 영상 (`samples/`)
| 파일 | 내용 |
|---|---|
| 01_신호위반_빨간불출발 | 빨간불에 출발한 차 (신호위반 1건) |
| 02_깜빡이미점등_모닝_좌측변경 | 깜빡이 없이 좌측 차선 변경 |
| 03_깜빡이미점등_빨간차_우측변경 | 깜빡이 없이 우측 차선 변경 |
| 04_정상_깜빡이켜고_차선변경 | 깜빡이 켜고 차선 변경 (위반 없음) |

### 처리 시간 (참고)
영상 1분당: Apple M 시리즈 맥 약 1~2분, NVIDIA GPU PC 약 1분, GPU 없는 PC 5~10분.

## 3. 이렇게 판단합니다

**차선 변경 · 깜빡이**
- YOLO11 로 차량을 찾고 추적 → 차의 가로 위치를 '차 폭' 단위로 계산 → 1차폭 가까이 옆으로 이동하면 차선 변경
- 변경 직전 4초 동안 차 뒷면 좌/우의 주황색 불빛이 0.35~1.6초 간격으로 2번 이상 깜빡이면 '켬'
- 내 차가 차선을 바꾼 구간은 제외

**신호위반**
- 화면에서 가장 앞의 차량 신호등을 찾아 색(빨강/노랑/초록) 판별
- 빨간불일 때 ① 신호등 아래 가상 정지선을 넘거나 ② 정지선 근처에서 교차로 쪽으로 출발한 차량 = 위반

## 4. 알려진 한계 (중요)
- **신호위반은 놓치는 경우가 많습니다.** AI Hub 신호위반 검증 영상 기준 위반 차량 검출률 약 12% (빨간불 직진 100클립 12%, 빨간불 좌회전 60클립 13%). 대신 엉뚱한 차를 위반으로 잡는 경우는 적게 맞춤 (100클립 중 10클립에서 1건 이상).
  빨간불 좌회전처럼 옆으로 가로지르는 차, 아주 작은 오토바이, 신호등이 화면에 안 보이는 영상은 잘 못 잡습니다.
- **차선 변경**은 AI Hub 진로변경 위반 영상 기준 약 37~46% 검출. 급커브·아주 먼 차·3초 이하 짧은 영상에 약합니다.
- 깜빡이는 차 뒷면이 보여야 판정됩니다. 역광·야간 번짐이 심하면 '미점등'으로 잘못 나올 수 있습니다.
- 결과는 **참고용**입니다. 신고 전에 반드시 클립을 직접 확인하세요.

## 5. 문제 해결
| 증상 | 해결 |
|---|---|
| `python3`/`py` 를 찾을 수 없음 | Python 설치 (Windows 는 "Add to PATH" 체크) 후 다시 실행 |
| 설치 중 오류 | 인터넷 확인 후 `.venv` 폴더를 지우고 다시 실행 |
| 브라우저가 안 열림 | `http://127.0.0.1:7860` 직접 입력 |
| 7860 포트 사용 중 | `python gui_app.py --port 7861` |
| 아주 느림 (Windows, NVIDIA GPU 있음) | https://pytorch.org 에서 CUDA 버전 torch 설치 명령으로 재설치 |
